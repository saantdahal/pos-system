CaféServe - QR-Based Restaurant Management System
[![Flutter](https://img.shields.io/badge/Flutter-3.x-blue![Node.js](https://img.shields.io/badge/Node.js-18.x![License](https://img.shields.io/badge/License-MIT-yellowA complete role-based restaurant management system with QR code ordering, real-time updates, and quantity bargaining. Customers scan table QR → browse menu → order → bargain with admin → track status.

✨ Features
Phone + OTP Registration (Twilio SMS)

Role-Based Access: Admin, Kitchen, Waiter, Customer

Restaurant Management: Menu, Tables, Staff QR

QR Code Ordering: Table-specific menu access

Real-time Updates: WebSocket order status

Quantity Bargaining: "Only 2 plates available?"

Multi-mode: Online backend + Offline localhost fallback

📡 Backend APIs
bash

# Auth

POST /api/auth/register # Send OTP
POST /api/auth/verify-otp # Create user

# Restaurants (Admin)

POST /api/restaurants # Create restaurant
GET /api/restaurants/my # List restaurants

# Menu

POST /api/restaurants/:id/menu # Add item
GET /api/restaurants/:id/menu # Get menu

# Orders

POST /api/orders # Place order
PUT /api/orders/:id/status # Update status

# WebSocket

WS /ws/restaurants/:id/orders # Real-time updates

   🗄️ Database Schema
   sql
   users: id, phone, name, role, created_at
   restaurants: id, name, owner_id, address, lat, lng
   restaurant_staff: restaurant_id, user_id, role
